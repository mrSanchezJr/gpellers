# Gpellers (ASIS-2AX-V) — Cross-Platform (.NET 8 & Avalonia UI)

Кроссплатформенная (Windows и Linux) версия приложения **ASIS-2AX-V (Gpellers)** для управления сканирующим контроллером ЧПУ (Inectra / GRBL) по **COM-порту** и **Wi-Fi (TCP сокет)**.

---

## 🌟 Ключевые возможности и архитектурные решения

1. **100% перенос функционала оригинала Windows WinForms:**
   - Монолитный, простой Code-Behind (`MainWindow.axaml.cs`) без избыточных абстракций ООП, строго в соответствии с требованиями.
   - Все оригинальные переменные, методы, алгоритмы растрового сканирования и протоколы сохранены 1:1.

2. **Автоматическая плавная адаптация и масштабирование (`Viewbox Stretch="Uniform"`):**
   - Всё окно заключено в контейнер `<Viewbox Stretch="Uniform">`.
   - Пользователь может просто тянуть за любой угол окна — интерфейс плавно и пропорционально увеличивается или уменьшается без искажений, сдвигов и наложений элементов.
   - Корректно отображается как на компактных сенсорных панелях (800x480, 1024x600), так и на 1080p, 2K и 4K мониторах.

3. **Специфика ASIS-2AX-V (Gpellers) в сравнении с G-write:**
   - **Блок "Подача воды 💧" (насос дозирования / ось Z):**
     * Кнопка `+` (подача воды): `G01 Z{stepHandZ} F{speedWater}` в `G91`.
     * Кнопка `-` (откачка воды): `G01 Z-{stepHandZ} F{speedWater}` в `G91`.
     * Скорость подачи (`speedWater`, мл/с): 10, 20, 100, 200.
     * Объём подачи (`stepHandZ`, мл): 1, 10, 50, 100.
   - **Кнопка "Дом" (`button13`):** в правом верхнем углу блока XY джога для отправки `$H\n` (поиск баз).
   - **План сканирования `gen()`:**
     * Учитывает время первичной прокачки воды (`comboBox6`, `start_w`).
     * На каждый проход растра инкрементирует координату Z переменной `timeWater`.
     * Заголовок файла: `; x1=...; y1=...; x2=...; y2=...; wtm=...; spd=...; stp=...`.

4. **Экранная клавиатура Numpad для сенсорных экранов:**
   - Плавающее окно с индикатором активного поля ("Точка A (X)", "Точка B (Y)" и т.д.).
   - Кнопка `⏎ Ввод` циклически переключает фокус по полям координат (`startPosX` → `startPosY` → `endPosX` → `endPosY`).

5. **Оригинальные иконки и графика:**
   - Все пиктограммы извлечены из `Form1.resx` и `Resources/` и помещены в `Assets/`.
   - Кнопки джога, кнопки генерации, возврата в начало, паузы, пуска и подачи воды имеют оригинальные иконки.

## 🚀 Запуск и сборка

### Быстрый запуск в режиме разработки:
```bash
dotnet run
```
или двойным кликом по файлу `run-windows.bat`.

### Публикация готовых релизов:
```bash
# Для Windows x64:
dotnet publish -c Release -r win-x64 --self-contained false -o bin\Publish\win-x64

# Для Linux x64 (автономный исполняемый файл без необходимости ставить .NET):
dotnet publish -c Release -r linux-x64 --self-contained true -p:PublishSingleFile=true -o bin\Publish\linux-x64
```
или запустите `build-all.bat`.

---

## 🐧 Запуск на Linux:
1. Скопируйте папку `bin/Publish/linux-x64` на целевой компьютер с Linux.
2. Дайте права на выполнение:
   ```bash
   chmod +x ./Gpellers
   ```
3. Запустите:
   ```bash
   ./Gpellers
   ```
   *(При использовании COM-порта убедитесь, что пользователь добавлен в группу `dialout`: `sudo usermod -aG dialout $USER`).*
